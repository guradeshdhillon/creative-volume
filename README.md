🎚️ Bizarre Frontend
Welcome to the Anti-UX Challenge! Inspired by the legendary "Worst Volume Control" internet trends, this event is a celebration of "creative frustration." Your goal is to throw every best practice out the window and design a volume controller that is technically functional, but absolutely agonizing to use.

🏆 Scoring & Judging Criteria
The winners will be decided based on the following metrics:

Creativity & Humor (40%): How unique is the concept? Does it make the judges laugh (or cry)?

The Frustration Factor (30%): How much effort does it take to move the volume from 0 to 100? The more "hostile" the design, the better.

Technical Functionality (20%): It must actually work. The volume should technically change the audio level of the embedded track.

AI Prompt Ingenuity (10%): How effectively did you use AI tools to generate this chaotic logic?

🚀 The Challenge
Your mission is to build a single-page web interface that features the most creatively worst volume control ever conceived.

The AI Twist: You are encouraged to use any AI tool (Gemini, ChatGPT, Claude, etc.) to help you brainstorm concepts and generate the code.

The Example: If you’re feeling stuck, check out the Team_Gravity subfolder in this repository. It contains an example of what a "creatively bad" implementation looks like.


The Participant Workflow (Step-by-Step)
1. Clone the Repository
If they haven't already, they need to get the code onto their machine:

git clone https://github.com/guradeshdhillon/creative-volume.git
cd creative-volume
2. Create a New Branch
This is the crucial step. They must move off the main branch to do their work.

# They should name the branch something descriptive
git checkout -b Team_Member1_Meber2
3. Create Your Team Folder
Create a new folder named after your team (e.g., Team_Member1_Member2).

Inside your folder, create an index.html and any necessary CSS/JS files.

Open the project in your browser to test your creation.
4. Push the Branch to GitHub
git add .
git commit -m "Add a message"
git push origin Team_Member1_Meber2
5. Open the Pull Request (PR)
Once they push, they need to:

Go to the GitHub repository page in the browser (github.com/guradeshdhillon/creative-volume/branches).

CLick on the 3 dot buttons on the right corner of the respective branch to be pushed to.

Click on New pull request

Add title and description

Click "Create pull request."

📢 Rules of Engagement
No Malicious Code: No infinite loops, browser-crashing scripts, or malware.

Keep it Frontend: Focus on HTML, CSS, and JavaScript.

Have Fun: The goal is to be as ridiculous as possible.

Happy De-Designing! May the most irritating slider win.
